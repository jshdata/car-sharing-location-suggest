# 카셰어링 차고지 입지 추천

인구·교통·주차장 등 공간 데이터를 분석하고, P-median 알고리즘을 활용해 카셰어링 차고지 후보지를 비교하는 데이터 분석 프로젝트입니다.

## 프로젝트 배경

카셰어링 차고지의 입지를 접근성, 수요성, 통행량, 가용성, 활동성의 다섯 지표로 검토합니다. 지역별 현황 분석과 공간 데이터 가공을 수행하고, 후보지 조합의 가중 거리 합을 비교합니다. 대전·인천 등 지역의 분석 자료를 포함합니다.

프로젝트 진행 순서: **카셰어링 차고지 추천 → 편의점 매출 분석 → WAHIS**.

## 구성

| 경로 | 내용 |
| --- | --- |
| `notebooks/` | 지역 EDA, 격자·거리 계산, 가중치 분석, P-median 후보지 비교 및 지도 작성 |
| `코드/` | 원본의 공통 데이터 가공 노트북 및 중간 산출물 |
| `크롤링/` | 카카오맵·관광 데이터 수집 노트북, 수집 결과와 참고 코드 |
| `data/` | 원본 ZIP에 포함된 인구·교통·주차장 등 데이터와 공간 파일, 데이터 출처 문서 |

주요 노트북은 `p_median 알고리즘.ipynb`, `가중치.ipynb`, `min-max 스케일링.ipynb`, `지도 만들기.ipynb`입니다. 파일명은 원본을 유지했습니다. 노트북 출력은 저장 용량과 불필요한 실행 기록을 줄이기 위해 제거했습니다.

## 분석 흐름

1. 지역별 인구, 차량·교통량, 교통 인프라와 차고지 현황 탐색
2. 공간 데이터와 격자 단위 지표 가공
3. 접근성·수요성·통행량·가용성·활동성 지표 및 가중치 검토
4. 공영주차장 등의 후보지를 대상으로 P-median 조합 비교
5. 점수화와 후보지 지도 시각화

## 실행 안내

```bash
python -m venv .venv
# Windows PowerShell
.venv/Scripts/Activate.ps1
pip install -r requirements.txt
jupyter lab
```

이 저장소는 당시 분석 자료를 정리한 아카이브입니다. 노트북에는 원래 작업 환경의 절대 경로, 외부 데이터 및 데이터베이스 연결을 사용하는 코드가 남아 있습니다. 실행 전 해당 경로를 로컬 `data/` 위치로 변경하고 필요한 외부 입력을 준비해야 합니다. 전체 분석의 일괄 실행이나 동일 결과 재현은 검증하지 않았습니다. `requirements.txt`는 노트북에서 사용한 주요 패키지의 목록이며 당시 환경의 고정 버전 명세는 아닙니다.

`min-max 스케일링.ipynb` 등에는 여러 실험이 함께 들어 있으므로 파일명만으로 최종 방법을 판단하지 말고 각 셀을 확인해 주세요. 원본 코드를 보존했으며 분석 정확도나 성능 수치를 새로 주장하지 않습니다.
